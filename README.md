# FlowDuo

A small demo application that provides an iPhone Duo like animation for ROG Flow X16 (and X13?)

Press space to calibrate the hinge angle when using raw accelerometer data for the angle calculation (default mode).


You can [download the binary](https://github.com/Iemand005/FlowDuo/releases/download/1.1.0/FlowDuo.exe) from [releases](https://github.com/Iemand005/FlowDuo/releases) to try it out for yourself, or clone the repository and compile it!
